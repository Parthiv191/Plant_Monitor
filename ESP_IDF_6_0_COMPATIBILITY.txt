## Quick Start

### Option 1: Upgrade to ESP-IDF 6.0
```bash
# Switch to new ESP-IDF version in VS Code
# Or from terminal:
cd ~/esp/esp-idf-6.0
source export.sh
cd ~/Dev/Plant_Monitor
idf.py fullclean
idf.py build
```

### Option 2: Keep ESP-IDF 5.4.x (Works Fine!)
```bash
# Project works perfectly as-is with 5.4.1
idf.py build
idf.py flash
```

## Verified APIs Used

All of the following APIs are confirmed stable across 5.4.x → 6.0+:

### ADC (esp_adc/adc_continuous.h)
- `adc_continuous_new_handle()`
- `adc_continuous_config()`
- `adc_continuous_start()`
- `adc_continuous_read()`

### WiFi (esp_wifi.h)
- `esp_wifi_init()`
- `esp_wifi_set_mode()`
- `esp_wifi_set_config()`
- `esp_wifi_start()`
- `esp_wifi_connect()`

### Event Loop (esp_event.h)
- `esp_event_handler_instance_register()`
- `WIFI_EVENT` / `IP_EVENT` enums
- Event handler callbacks

### HTTP Server (esp_http_server.h)
- `httpd_start()`
- `httpd_register_uri_handler()`
- `httpd_resp_*()` functions

### GPIO (driver/gpio.h)
- `gpio_config()`
- `gpio_set_level()`

### Others
- FreeRTOS: `xTaskCreatePinnedToCore()`, `vTaskDelay()`
- NVS: `nvs_flash_init()`, `nvs_flash_erase()`
- MDNS: `mdns_service_add()`, plant_mdns_start()
